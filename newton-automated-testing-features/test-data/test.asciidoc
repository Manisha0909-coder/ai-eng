== Introduction

Welcome to the company! This guide outlines everything you need to know during your first 30 days.

== Pre-Joining Checklist

* Submit signed offer letter
* Complete background verification
* Set up corporate email
* Install required software tools

== IT Security Guidelines

IMPORTANT: All employees must complete security training within 7 days of joining.

* Use strong passwords (minimum 12 characters)
* Enable two-factor authentication on all accounts
* Never share credentials
* Report suspicious activity to security@company.com
