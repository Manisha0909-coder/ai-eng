# Brightness Toggle or Adjustment

## US001

As a user, I want to toggle between light and dark themes, so that I can adjust the appearance of the application to my preference or environment.

**Acceptance Criteria:**
    - A theme toggle option is available and accessible from the interface.
    - User can switch between light mode and dark mode with a single action.
    - The selected theme is applied immediately across the entire application.
    - The theme resets to dark mode by default every time the user logs in, regardless of the previously selected theme.
    - The toggle clearly indicates which theme is currently active.
