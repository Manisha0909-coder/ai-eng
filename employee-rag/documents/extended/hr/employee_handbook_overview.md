# Employee Handbook Overview

**Version:** 3.1
**Effective Date:** 2026-01-01

## Purpose

This handbook is the starting point for understanding how things work here.
It summarizes company-wide policies and points to the detailed policy
document for each topic. Where this overview and a detailed policy
disagree, the detailed policy governs.

## How Policies Are Organized

Policies are grouped by department: HR (leave, conduct, grievances,
performance, onboarding, benefits), IT (security, access, data privacy,
remote work equipment, software), Finance (expenses, travel, procurement),
and Security (incident response, physical safety, visitor access). Each
policy document has a version number and an effective date in its header;
always check you're reading the current version, not a superseded one.

## Code of Conduct

All employees are expected to follow the Code of Conduct, which covers
workplace behavior, conflicts of interest, confidentiality, and how to
report concerns. See `code_of_conduct.txt` for the full policy.

## Leave

Annual leave, sick leave, maternity leave, and work-from-home allowances are
covered in the Employee Leave Policy (`employee_policy.txt`). Leave without
pay (LWP) for circumstances beyond standard leave categories is covered
separately in the Leave Without Pay Policy.

## Remote Work

Remote work touches three different policies, each covering a different
angle:

- **Frequency** — how often you can work from home: see the Employee Leave
  Policy's Work From Home section.
- **Conduct** — behavior expectations while working remotely (core hours,
  cameras on for meetings): see the Code of Conduct's Remote Work Conduct
  section.
- **Equipment** — what the company provides and reimburses for your home
  setup: see the Remote Work Equipment Policy.

## Benefits

Benefits differ by work location. India-based employees should refer to the
Benefits Overview (India); US-based employees should refer to the Benefits
Overview (US). Amounts and programs are not interchangeable between the two.

## Getting Help

- General HR questions: HR department.
- Workplace conduct concerns: HR or the anonymous ethics hotline (see Code
  of Conduct).
- Formal grievances: see the Grievance Policy for the escalation process.
- IT access or security issues: IT Helpdesk.
