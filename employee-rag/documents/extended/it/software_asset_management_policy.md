# Software Asset Management Policy

**Version:** 1.3
**Effective Date:** 2025-11-01

## Approved Software List

Employees may only install software from the IT-maintained Approved
Software List, available on the IT portal — consistent with the IT
Security Policy's rule that employees may not install arbitrary software
on company laptops. Requesting an addition to the list requires a business
justification submitted to IT.

## License Compliance

IT tracks software licenses centrally. Installing unlicensed or
personally-purchased software that duplicates a company-licensed tool is
not permitted, to avoid license-compliance violations.

## Software Request Process

1. Submit a request through the IT portal, including business
   justification.
2. Requests under **$50/user/year** (or equivalent) are approved by the
   requester's manager alone.
3. Requests at or above that threshold require IT and Finance approval,
   following the same approval-by-amount pattern as the Procurement
   Policy.

## Browser Extensions and SaaS Tools

Browser extensions and free-tier SaaS tools that access company data
(e.g. connect to email or calendar) require IT security review before use,
even if no purchase is involved — the review is for data-access risk, not
cost.

## Annual Audit

IT conducts an annual software audit every **Q1**, removing unused
licenses and flagging any software not on the Approved Software List for
manager review within **30 days**.
