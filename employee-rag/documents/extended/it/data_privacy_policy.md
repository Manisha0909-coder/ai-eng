# Data Privacy Policy

**Version:** 1.8
**Effective Date:** 2026-01-01

## Data Classification

| Level | Examples | Handling |
|---|---|---|
| Public | Marketing materials | No restrictions |
| Internal | Internal memos, org charts | Employees only |
| Confidential | Financial reports, source code | Need-to-know, per Code of Conduct |
| Restricted | Customer PII, health data | Encrypted at rest, access-logged |

## Data Protection Officer (DPO)

The DPO oversees compliance with this policy and data-protection law. Any
request involving Restricted data (new system, new vendor, new data
export) requires DPO sign-off before proceeding.

## Retention Schedule

- HR records (including performance reviews): **3 years** after last
  activity, per the Performance Review Policy.
- Financial/expense records: **7 years**, per statutory requirement.
- Security incident logs: **2 years**, per the Incident Response Policy.
- Customer data: per the applicable customer contract, never less than the
  statutory minimum for the relevant jurisdiction.

## Data Subject Requests

Employees or customers requesting access to, correction of, or deletion of
their personal data should submit the request to the DPO. The DPO
responds within **30 days**, extendable once by 30 days for complex
requests with notice to the requester.

## Data Breach Notification

A suspected breach involving Restricted data must be reported to the DPO
within **2 hours** of discovery — a shorter window than the IT Security
Policy's general 24-hour phishing-report requirement, because breach
notification has its own statutory clock. See the Incident Response Policy
for the full breach-handling procedure.

## Third-Party Data Sharing

Sharing Confidential or Restricted data with a vendor requires a signed
data-processing agreement, reviewed by the DPO, before any data transfer
begins.
