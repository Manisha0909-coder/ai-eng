Panel 7 · Anatomy summary — labeled
Reference for implementation. Each numbered callout maps to a DOM layer in HtmlCarousel.tsx.
1

Count label

Always shown above the rail. "N chart" / "N charts". text-2xs text-text-muted

2

Snap-scroll rail

overflow-x: auto · scroll-snap-type: x mandatory · scrollbar hidden · gap-3. Each slide is 100% wide.

3

Slide card

rounded-xl border border-border-main bg-surface shadow-sm. Contains title bar + iframe.

4

Chart title bar

Icon + chart title string. text-xs font-medium text-text-main. Hidden when title is null.

5

Navigation row

Prev button · counter (X / N, font-mono tabular-nums) · Next button. Hidden when N = 1.

6

Height adaptation

Rail height = max of all measured iframe heights. transition: height 0.3s ease-out. Min 240 px.
